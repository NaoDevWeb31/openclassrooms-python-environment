# Mettez en place votre environnement Python

Exercices et travaux pratiques réalisés dans le cadre du cours **« Mettez en place votre environnement Python »** proposé par [OpenClassrooms](https://openclassrooms.com/fr/courses/6951236-mettez-en-place-votre-environnement-python).

## Objectifs du cours

- Configurer un environnement de développement Python.
- Utiliser le terminal et les outils de développement.
- Comprendre et gérer les dépendances d'un projet Python.
- Installer et gérer des paquets Python.
- Travailler avec des environnements virtuels.
